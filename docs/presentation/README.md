## 원본 PPTX에 대하여

원본 `.pptx`는 **83 MB**이며, 이 중 **54 MB가 슬라이드 12에 삽입된 시연 동영상**(`media1.mp4`)입니다.

git 저장소에는 PDF 변환본만 포함했습니다.

- GitHub는 50 MB 초과 파일에 경고, 100 MB 초과 파일은 거부합니다.
- 동영상·이미지 같은 바이너리는 변경 시마다 전체가 히스토리에 누적되어 clone 용량이 계속 커집니다.

원본 PPTX와 시연 영상이 필요하면 **GitHub Releases**에 자산으로 첨부하는 방식을 권장합니다.
(저장소 → Releases → Draft a new release → 파일 첨부) 릴리스 자산은 git 히스토리에 들어가지 않아
clone 용량에 영향을 주지 않으면서 링크로 공유할 수 있습니다.

> 슬라이드 3의 "작업 시간 75~80 % 단축 / 위반 검출률 90~95 %"는 본 시스템의 측정치가 아니라
